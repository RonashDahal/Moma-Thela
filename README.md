# 🥟 Momo Thela — Web Design Practical Project

Welcome to the official repository for **Momo Thela**, a responsive, modern website designed for a food cart / restaurant specializing in authentic steamed, fried, and specialty momos. 

This project was built as part of the **Website Design Practical** coursework to demonstrate core front-end design concepts, responsive web layouts, UI/UX aesthetics, and interactive web elements.

---

## 📌 Project Overview

**Momo Thela** brings the vibrant experience of street-food momo carts into a clean, modern digital space. The goal of this practical project is to create an intuitive and visually appealing landing website that allows customers to explore the menu, check daily specials, learn about the food cart, and easily locate or contact the business.

### Key Highlights
- 🎨 **Modern & Clean UI**: Vibrant colors matching appetizing food aesthetics.
- 📱 **Fully Responsive Layout**: Seamless viewing experience across mobile phones, tablets, and desktop computers.
- 🥟 **Interactive Menu Section**: Clear categories for Steamed, Fried, Jhol, and Special Momos with pricing and descriptions.
- 📍 **Location & Contact Info**: Easy access for customers to find the cart and make inquiries.
- ⚡ **Lightweight & Fast**: Pure standard web technologies for high performance and smooth navigation.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic document structure and markup.
- **CSS3**: Custom styling, Flexbox/Grid layouts, smooth transitions, and media queries for responsiveness.
- **JavaScript (ES6+)**: Interactive UI logic, mobile menu toggling, dynamic DOM updates, and basic form validations.
